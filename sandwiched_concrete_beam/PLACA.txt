END PLATE AND RODS - SANDWICH CONNECTION (IPE 200 to concrete beam 300x350)
==========================================================================
Source: sandwiched_connection.m (inputs), results in run_output.txt.
Two identical plates, one on each side face of the concrete beam, tied by the
same 4 rods. Dimensions in mm.

PLATE
  Material ......... ASTM A36, t = 12
  Size ............. 140 wide x 220 high
  Position ......... top edge flush with the top of the IPE top flange and with
                     the top of the concrete beam; IPE web on the plate's
                     vertical centreline; plate extends 20 below the bottom
                     face of the IPE bottom flange; plate bottom edge is 130
                     above the bottom face of the concrete beam.

HOLES (4 x dia. 18, standard hole for 16 mm rods, AISC Table J3.3M)
  Horizontal ....... gage 55: x = -27.5 and +27.5 from the plate centreline
                     (edge distance to the plate sides 42.5)
  Tension row ...... 42 below the plate top edge (33.5 below the inner face of
                     the top flange)
  Shear row ........ 150 below the plate top edge (70 above the plate bottom
                     edge; 41.5 above the inner face of the bottom flange)
  Rod centre to web face 24.7; to the web weld toe (6 mm fillet) 18.7.

          <-------------- 140 -------------->
          +---------------------------------+  -- 0   (top of IPE / concrete)
          |=========== top flange ==========|     CJP groove weld
          |                                 |
          |      O          |          O    |  -- 42   tension row
          |                 |               |
          |                 | web           |
          |                 |               |
          |      O          |          O    |  -- 150  shear row
          |                 |               |
          |=========== bottom flange =======|  -- 191.5 / 200
          |                                 |  -- 220  plate bottom (ext 20)
          +---------------------------------+
                 <-- 27.5 -->|<-- 27.5 -->
                     (g = 55)

WELDS (E70XX)
  Top flange ....... CJP groove weld, flange beveled (plate flush on top, no
                     room for an outside fillet). Prequalified joint per AWS
                     D1.1, chosen by the fabricator. Check: base metal 0.67.
  Bottom flange .... 6 mm fillet, both faces: outer face 100 long, inner faces
                     2 x 35.2 (between flange tip and root radius). Check 0.54.
  Web .............. 6 mm fillet both sides, full straight web height 159.
                     Check 0.32 (tension + shear, see PENDIENTE item 4d).

RODS
  Material ......... ASTM A193 B7, diameter 16, threaded (supplier mill
                     certificate required, PENDIENTE item 1)
  Quantity ......... 4 per joint, through both plates and the concrete beam
  Installation ..... cast in before pouring (in position through both plates),
                     hand tightened (not torqued). Washer + nut each end.
  Length ........... about 380 = 300 (beam) + 2 x 12 (plates) + 2 x (washer +
                     nut + 3 threads); confirm nut/washer heights with supplier.

CONCRETE BEAM (at the joint)
  - Rods run parallel to the stirrup legs: place them between stirrups.
  - Top rods sit on top of the top longitudinal bars (rod bottom at 50 = bar top).
  - 2 extra closed stirrups (135 deg hooks), one each side of the rod pair, as
    close to the rods as possible (splitting control, ACI 17.9.1).
  - Stirrup spacing <= 110 in the torsion zone (PENDIENTE item 3).
