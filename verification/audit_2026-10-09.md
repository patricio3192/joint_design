# Audit of the code references in lib/ (2026-10-09)

Read-only audit by a cloud agent, without the PDFs: it compared the code with
the reference files (EQUATIONS.txt, manuals) and checked SI conversions and
clause logic from knowledge of the codes. Nothing here was checked against a
page. Items S1 and S2 were re-read in the code and are confirmed.

Classes: A = in the reference file with clause and PDF page; B = clause only;
C = used in the code, absent from the reference file; D = own engineering model.

## Steel: errors and mismatches
- **S1 (confirmed). M5, weak-axis flexure of the HSS 200x100x4 column**
  (lib/collar_joint/dmj_lib.m:473 `0.90*Zcy*c.Fy`, and lib/direct_weld_joint/dwj_lib.m:253).
  In weak-axis bending the compression flange is the 200 mm wall: b/t = (200 -
  3x4)/4 = 47 > lambda_r = 1.40 sqrt(E/Fy) = 39.6 (Fy 250) -> slender flange,
  AISC F7.2(c) (effective section modulus), not 0.9 Fy Z. Audit estimate:
  phi Mn from 21.1 to about 17.4 kNm (-17 %); recompute it from the page. The
  hand check (lib/collar_joint/joint10_handcheck.pdf) repeats the 21.089 kNm.
  The collar manual's compactness note covers the strong axis only.
- **S2 (confirmed). Shear-tab net areas without the +2 mm of AISC B4.3b**:
  P6, P7, P10 (dmj_lib.m:449-451, 463) use dh = 18 (J.nl.dh, dmj_lib.m:85).
  The manual's history item 2 says this was fixed; it came back in the
  shear-tab code.
- S3. No library applies the 0.93 t design wall thickness of HSS (B4.2). The
  direct-weld manual and sheet say so; the collar manual and sheet are silent.
- S4. Collar T3, shear lag U: manual describes the 360-10 stepped rule
  (l = 100, U = 0.75); code uses the 360-16 formula with l = 80 (U = 0.74).
  Manual and hand check cite "J4.2" for flange rupture; it is J4.1(b) (the code is right).
- S5. Seat inputs drifted from the manual: manual e = 40, share = 1.0,
  bwidth/nwidth; code e = gap + L_lap/2 = 55, share = 0.5, single wmode
  (dmj_lib.m:50-72, 347-355); code comments disagree on the default wmode.
- S6. CIDECT hd taken as L_lap = 80 (dmj_lib.m:314, 828) though the plate
  projects gap + L_lap = 95 (conservative). Pbf unfactored (INFO check only).
- S7. Direct weld F3 uses J10-2 (5k), F4 uses J10-4 (0.80) and J10-8 without the
  50 % end reduction (dwj_lib.m:186-200). The column ends at the top of the
  beams, so the near-end forms apply: J10-3 (2.5k), J10-5 (0.40), J10.5
  halving. Not governing at joint 10.
- S8. Direct-weld manual §3 presents phi = 0.90 as the code factor for wall
  shear (C1); J4.2 gives 1.00 (the collar manual says 0.90 is a deliberate margin).
- S9. S6 and W3 (dmj_lib.m:405-407, dwj_lib.m:241-243): when h/tw >
  2.24 sqrt(E/Fy) phi becomes 0.90 but Cv1 stays 1; G2.1(b) gives Cv1 < 1 when
  h/tw > about 80. Not triggered for IPE 160.
- S10. P9, P11, W2 and the validity limits cite AISC 360-10 (superseded); B/t <= 40 hard-coded.

## Concrete: mismatches
- C1. check_end_plate_column.m:97 uses a fixed 25 mm clear between parallel
  bars; EQUATIONS.txt says max(25, db, 4/3 dagg). (lib/joint_model jm_clash
  uses the full rule.)
- C2. Side-face blowout (check_end_plate_column.m:226) lacks the ca2 < 3 ca1
  factor (17.6.4.1.1) and the group rule (17.6.4.2). Not triggered (hef 309 <= 368).
- C3. check_sandwich_beam.m: eps_t < 0.005 flag; ACI 318-19 Table 21.2.2 uses
  eps_ty + 0.003 = 0.0051 for fy 420 (printed flag only).
- C4. check_sandwich_beam.m prints the 9.7.5.1 / 9.7.5.2 torsion-bar rules as
  met without testing them; B4.1b compactness printed, not enforced
  (sandwich_column enforces it).
- C5. Vc <= 0.42 sqrt(f'c) bw d listed but not applied (no effect with Nu = 0).
- C6. Wording: end-plate file says 15.4.2.4 "2 x distance to side face"; the
  code correctly uses twice the distance from the beam axis to the column side.
- Not checkable without the PDFs: DG 39 Eq. 5-4a (1.10, gamma_r), CIDECT 3.17.
